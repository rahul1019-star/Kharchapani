# Kharcha Pani — Android source prototype

## Is version mein
- Native Android app source code (Kotlin + Jetpack Compose)
- 5 mini-games: Quick Quiz, Math Sprint, Memory Challenge, Word Scramble, Reaction Tap
- Demo points and daily bonus
- No sign-in, server, advertisements, deposits, wagers, cash prizes, UPI or withdrawals

## Build karne ke liye
1. Android Studio install karein.
2. Is ZIP ko extract karein.
3. Android Studio mein `KharchaPani` folder open karein.
4. Gradle sync hone dein.
5. Android SDK 35 aur JDK 17 configured rakhein.
6. Run button se emulator/Android phone par test karein.
7. APK banane ke liye: Build > Build APK(s).

## Important
Yeh starter source project hai, tested/released APK nahi. Build ke waqt Gradle/Android Studio version ke hisaab se adjustments ki zaroorat ho sakti hai. Scores app ke current session mein hain; app band karne par permanent account/database save nahi hota.

Points ki koi cash value nahi hai. Cash-out, stakes, paid entry, monetary prizes, ya redeemable rewards add na karein bina current Indian law, applicable rules, app-store policies aur professional legal advice ki review ke. Social/free-to-play classification automatic guarantee nahi hai.
